# 管球平衡调试交接文档

## 一、工程概述

**赛题**：2026 电子设计竞赛 H题 — 车载平衡滚球运动控制系统  
**分支**：`ball-beam-pid-debug-tuning`（从 `小球管道平衡` 分出）  
**芯片**：MSPM0G3507 (Cortex-M0+, 80MHz, LQFP-64)  
**RTOS**：FreeRTOS  
**IDE**：Keil uVision V5.43 + ArmClang V6.24  

### 管球控制原理

```
MaixCam(YOLO检测) → 钢珠X坐标(像素) → 串级PID → 步进电机倾角 → 管道倾斜 → 钢珠滚动
     UART3 PB2/PB3         15字节帧          位置环→速度环    Emm_V5 UART1 PB6/PB7
```

**控制结构**：速度级联
- 外环（位置环）：`期望球速 = Kp_pos × 位置误差`
- 内环（速度环）：`倾角脉冲 = Kp_vel × (期望球速 - 实际球速)`
- 球速通过相邻帧坐标差分 + 低通滤波估计

### 2.2 UART0 引脚迁移

**原 PA0/PA1 → 改为 PA10/PA11**

PA0/PA1 是 **5V 容忍开漏 IO (ODIO)**，UART TX 模式下只能拉低、高电平靠外部上拉，无上拉时信号不可靠。PA10/PA11 是标准推挽 GPIO，测试工程已验证可靠。

改动文件：`main.syscfg`（UART0 rxPin/txPin 引脚分配）

### 2.3 调参过程中发现并修复的 Bug

| Bug | 现象 | 修复 |
|-----|------|------|
| SLEWB 与 motor_offset 交互 | SLEWB 比较原始输出与已加偏置的 motor_target，偏置阻止输出向一侧变化，球完全不动 | 改为比较 `motor_target - motor_offset`（上次原始输出） |
| HOMING 期间电机加偏置 | 管道"水平"时实际倾斜，球滚到端部 | HOMING 电机回 0 位（不加偏置），1 秒后进入 TRACKING |
| JY61P 占用 UART0 ISR | 调试分支 UART0 ISR 与 JY61P 帧解析冲突 | `#if BALL_TUNING_DEBUG_ENABLE` 条件编译，调试分支不编译 JY61P ISR |

### 2.4 控制算法改进

| 改进 | 说明 |
|------|------|
| 非对称倾角限制 | `max_tilt=200`(正/上坡), `max_tilt_neg=80`(负/下坡)。正方向需大倾角克服摩擦，负方向限制防重力加速振荡 |
| 电机机械偏置补偿 | `motor_offset=20`，管道水平时球自然偏向低x，加偏置修正 |
| 球速低通滤波 | `vel_filter_alpha_milli=600`，抑制视觉坐标量化噪声导致的球速估计跳变 |
| 球速自适应倾角限制 | 球速 >50px/s 时按比例降低最大正倾角，防止球过度加速导致大超调 |
| 死区补偿 | 球静止且误差 >容差时，给固定脉冲突破静摩擦 |
| 到达判定加球速约束 | 不仅位置在容差内，球速也需 <20px/s 才算到位，防止高速穿越误判 |

### 2.5 最终参数

```c
// 速度级联
g_t2_kp_pos          = 5000;   // 位置环增益
g_t2_kp_vel          = 1500;   // 速度环阻尼
g_t2_max_desired_vel = 120;    // 期望球速限幅 (px/s)

// 非对称倾角
g_t2_max_tilt        = 200;    // 正方向最大倾角 (上坡)
g_t2_max_tilt_neg    = 80;     // 负方向最大倾角 (下坡防振荡)
g_t2_tilt_sign       = 1;      // 倾角方向

// 死区补偿
g_t2_dead_zone       = 30;     // 触发阈值
g_t2_dead_boost      = 90;     // 补偿脉冲
g_t2_dead_vel_th     = 10;     // 球速 <此值才算静止
g_t2_motor_offset    = 0;     // 物理校零后不需要偏置

// 位置保持补偿 (容差内施加)
// 方式1: 线性公式 (标定表禁用)  output = hold_gain × (target_x - hold_center_x) / 1000
// 方式2: 标定表插值 (标定表使能)  见下方 "位置保持标定表"
//   output = task2_lookup_hold_tilt(target_x)

// 到达判定
g_t2_tolerance_px    = 10;     // 位置容差 (px)
g_t2_reached_vel_px_s = 20;    // 到位球速上限 (px/s)
g_t2_stable_time_ms  = 500;    // 稳定持续时间 (ms)

// 滤波
g_t2_vel_filter_alpha_milli = 600;  // 球速低通 (1000=不过滤)
g_t2_output_slew_pulses     = 0;    // 输出变化率限制 (0=关)

// 电机参数 (宏定义, 需重编译)
TASK2_MOTOR_VEL_RPM  = 60;    // 电机转速
TASK2_MOTOR_ACC      = 30;    // 电机加速度
TASK2_MOTOR_RAF      = 1;     // 绝对位置模式
TASK2_HOMING_TIME_MS = 200;   // HOMING 等待 (从1s降到0.2s)
```

### 2.6 位置保持标定表

**问题**：管壁不同位置摩擦力和局部坡度不同，恒定的线性保持补偿无法在所有位置保持球静止。

**方案**：标定每个位置的保持倾角，运行时查表线性插值。

**标定表存储** (RAM, 掉电丢失):
```c
#define HOLD_CAL_MAX_POINTS  16
volatile int32_t g_hold_cal_x[HOLD_CAL_MAX_POINTS];     // 标定位置(像素)
volatile int32_t g_hold_cal_tilt[HOLD_CAL_MAX_POINTS];  // 该位置保持倾角(脉冲)
volatile int32_t g_hold_cal_count  = 0;                   // 已标定点数
volatile bool    g_hold_cal_enabled = false;               // 标定表使能
```

**查表插值函数** `task2_lookup_hold_tilt(target_x)`:
- 标定表使能且≥2个点 → 在标定点之间线性插值
- 否则 → 回退线性公式 `hold_gain × (target_x - center_x) / 1000`

**标定命令**:
```
TILT <pulses>             直接控制电机倾角，绕过PID (用于标定)
CALSET <idx> <x> <tilt>  写入第idx个标定点
CALCLR                   清空标定表
CALEN                    使能标定表
CALDIS                   禁用标定表 (回退线性公式)
CALLIST                  输出当前标定表
```

**标定脚本** `scripts/ball_beam_calibrate.py`:
```bash
# 自动模式 (二分法搜索每个位置的保持倾角)
python scripts/ball_beam_calibrate.py --port COM19

# 用PID先把球送到每个位置再标定
python scripts/ball_beam_calibrate.py --port COM19 --use-pid

# 手动模式 (人工确认球是否稳定)
python scripts/ball_beam_calibrate.py --port COM19 --manual

# 自定义标定位置
python scripts/ball_beam_calibrate.py --port COM19 --positions 105,135,165,195,225
```

**标定流程**:
1. 确保机构已校零 (FREE → 手动水平 → ZERO)
2. 运行标定脚本
3. 对每个位置，脚本用二分法找到使球静止的倾角
4. 标定完成后自动下发 CALCLR + CALSET + CALEN
5. 标定结果保存到 `logs/hold_calibration_*.csv`
6. 后续运行调参脚本时可加 `--cal-file logs/hold_calibration_xxx.csv` 自动上传

**运行时使用标定表**:
```bash
python scripts/ball_beam_tune.py --port COM19 --cal-file logs/hold_calibration_xxx.csv ...
```

## 三、未解决的问题

### 3.1 ⚠️ 调节时间太长（主要问题）

**现象**：球到达 ±10px 容差需要 **3-4 秒**，体感"小球太慢"。

**根因分析**：

1. **非对称倾角限制的代价**：负方向 `max_tilt_neg=80` 限制了下坡最大倾角，球速被压到 60-80px/s。这是为了防止振荡做的妥协——提高负方向倾角会导致发散振荡。

2. **球速自适应倾角限制**：球速 >50px/s 时进一步降低正方向倾角，虽然消除了大正步振荡，但也限制了正方向最大球速。

3. **电机响应速度**：`VEL_RPM=60, ACC=30`，电机从一个位置翻转到另一个位置需要约 100-200ms，刹车有延迟。曾尝试 `VEL_RPM=120, ACC=10`（更快），但加剧了振荡。

4. **HOMING 等待 1 秒**：每次 `START` 后球要等 1 秒才开始跟踪。

**可能的优化方向**：
- **前馈控制**：根据目标距离预计算倾角曲线，提前开始刹车，减少末端减速时间
- **增益调度**：远距离用高增益快到达，近距离降低增益防振荡（当前是固定增益）
- **电机加速度优化**：找到不引起振荡的最大电机加速度（当前 ACC=30 偏保守）
- **减小 HOMING 时间**：1s→0.5s，前提是球已停稳
- **提高 max_vel**：当前 120px/s，如果振荡可控可以提高到 150-180

### 3.2 无线串口丢字节

**现象**：`DEADB`、`SLEWB`、`MOFF` 等多参数命令偶尔丢失，遥测行被截断导致自动脚本分析出错（出现 err=1003 等假值）。

**影响**：自动调参脚本不可靠，需要多次手动发送命令确认。`PIDB` 和 `LIMIT` 命令相对可靠。

** workaround**：固件默认值已设为最佳参数，不需要频繁发命令。调参时只通过 `PIDB`/`LIMIT` 微调。

### 3.3 正方向最终精度

**现象**：正方向（上坡）目标有时差 8-9px 到位（如 225 目标停在 217）。

**根因**：`dead_boost=90` 不足以克服最后几像素的静摩擦。提高 dead_boost 会导致极限环振荡。

**可能的优化**：加微弱积分项（仅小误差区启用），缓慢累积输出突破摩擦。

### 3.4 PB18 引脚冲突（WS2812 vs 电磁铁）

SysConfig 中 PB18 配置为 `GPIO_MAGNET`（电磁铁），但 `ws2812.c` 也使用 PB18 作为 WS2812 数据线。`main.c` 同时调用 `magnet_init()` 和 `ws2812_init()`。需确认实际硬件接哪个。

### 3.5 调试分支与生产分支差异

调试分支 `BALL_TUNING_DEBUG_ENABLE=1` 的影响：
- **禁用** JY61P 姿态服务、巡线服务、速度环服务
- **禁用** 菜单系统（PB21 改为 ESTOP）
- **启用** UART0 调参串口（PA10/PA11）、命令任务、遥测任务
- UART0 引脚从 PA0/PA1 改为 PA10/PA11

**合并回生产分支时需要**：
1. 将最终参数写入 `control2.c` 默认值（已完成）
2. 将非对称倾角 `g_t2_max_tilt_neg` 和球速自适应限制加入生产代码
3. 删除调试专用代码（命令解析、TEL 遥测、Python 脚本）
4. 恢复 UART0 引脚为 PA0/PA1（如果生产环境用 JY61P）或保持 PA10/PA11
5. 恢复 `BALL_TUNING_DEBUG_ENABLE=0`

## 五、调参历程简述

1. **建立调参框架**：UART0 串口命令 + TEL 遥测 + Python 脚本
2. **发现 PA0/PA1 是开漏 IO**：改为 PA10/PA11 解决串口不可靠
3. **初调 kp_vel**：200→600→1000→2500，发现 2500 大步超调最小（26px）
4. **发现机械偏置**：球水平时偏向低 x，加 motor_offset=20
5. **发现发散振荡**：大步长时球越摆越大，根因是负方向倾角过大 + 电机反向延迟
6. **非对称倾角**：max_tilt=200(正), max_tilt_neg=80(负)，消除发散振荡
7. **发现目标点极限环**：kp_vel=3000 导致目标点附近持续 ±15px 振荡
8. **降低 kp_vel=1500**：消除大部分目标点振荡
9. **球速自适应倾角限制**：消除大正步残余振荡（39px→0px）
10. **当前状态**：稳定无振荡，但调节时间 3-4 秒偏长
