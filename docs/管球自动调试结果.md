## MaixCam 串口协议

UART3，PB2/PB3，115200 8N1，大端 8 字节帧：

```text
0xFE + x(uint16) + vx(int32, px/s) + 0xFD
```

- `x`：钢球中心 X 像素坐标。
- `vx`：MaixCam 端 `track_vx(px/ms) * 1000` 后发送，因此 MCU 端直接按 `px/s` 使用。
- `x=0xFFFF`：当前帧没有真实检测到钢球。
- MaixCam 的短时预测框只用于画面显示，不再作为 MCU 闭环反馈。

## 管球控制参数

```text
g_t2_target_x                 = 165
g_t2_kp_pos                   = 3000
g_t2_kp_vel                   = 1200
g_t2_max_desired_vel          = 80 px/s
g_t2_max_tilt                 = +120 pulses
g_t2_max_tilt_neg             = -80 pulses
g_t2_vel_filter_alpha_milli   = 250
g_t2_dead_zone                = 30
g_t2_dead_boost               = 60
g_t2_pos_static_tilt          = 120 pulses（远端启动）
g_t2_hold_gain_milli          = 0
g_t2_tolerance_px             = 10
g_t2_reached_vel_px_s         = 20
g_t2_stable_time_ms           = 500
```

高 X 方向存在明显静摩擦，采用两级有界启动：

- 正向误差 ≥30 px：`+120 pulses`，最长 700 ms；
- 正向误差 10～29 px：`+100 pulses`，最长 180 ms；
- 检测到球速 ≥10 px/s、进入目标容差或切换目标时立即取消；
- 每次启动后进入 500 ms 冷却。

该策略解决中心位置偶发长时间不启动，同时避免在正端附近用 +120 导致大幅过冲。

## 安全与恢复

- UART0（PA10/PA11，COM19）提供 `ESTOP/CLR/START/START3` 和在线参数命令。
- `START/START3` 为幂等命令，ACK 丢失重试不会重复初始化控制器。
- 每次启动前发送 X42S `0x0E 0x52` 解除堵转保护，再使能、设置位置模式参数。
- 步进驱动器使用手册规定的 `0xFD` 绝对位置模式，`mode=1`。
- 视觉丢失时保留最后真实位置：边缘丢失只执行 700 ms、45 脉冲的向内回收；超时后回水平。
- PB21 在调试固件中为硬件 ESTOP。

结果满足题目第三问：

- 总时间 ≤ 5 s

- 最终在 -5 cm 附近稳定
