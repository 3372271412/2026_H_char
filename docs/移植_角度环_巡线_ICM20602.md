## 四、line_tracking_service.c 适配说明

原版 `line_tracking_service.c` 依赖 history 版的 `distance_control` 简单进度模块
(3参数 start / 2参数 update)。

当前工程的 `distance_control` API 不同（含 brake_margin 状态机，5参数 start /
4参数 update），因此移植版 **内联了等价的简单距离进度逻辑** (`lt_distance_t`)，
不再依赖 `distance_control` 组件，避免 API 冲突。

## 五、使用方法

### 启用巡线 + 直角弯功能
1. 在 `app_tasks.c` 的 `app_tasks_start()` 中：
   - 取消注释 `speed_loop_task` 创建（巡线需要速度环运行）
   - 取消注释 `tracking_task` 创建
   - 注释掉 `control_task` 创建（Ball&Beam 与巡线不能同时运行）
2. 调用 API 启动巡线：
   ```c
   app_tasks_start_line_tracking(50000, 50);  // 目标50000脉冲, 基础速度50RPM
   ```
3. 读取巡线状态：
   ```c
   app_line_tracking_status_t status;
   app_tasks_get_line_tracking_status(&status);
   ```

### 启用 yaw 角度环（不巡线）
1. 在 `app_tasks_start()` 中：
   - 取消注释 `speed_loop_task` 创建
   - 取消注释 `yaw_loop_task` 创建
2. 设置 yaw 目标：
   ```c
   app_tasks_set_yaw_target(60, 900);  // 60RPM基础速度, 90°目标
   ```
3. 等待到位：
   ```c
   app_tasks_wait_yaw_settled(5000);  // 最多等5秒
   ```

### 启用 ICM20602（未来需要时）
1. 在 SysConfig 中添加 I2C0 外设 (PA0 SDA / PA1 SCL, 400kHz)
2. 将 `icm20602.c` 和 `i2c_bus.c` 加入 Keil 工程编译
3. 在 `app_tasks.c` 中用 ICM20602 替换 JY61P 的 attitude_task

## 六、调参指南

### 巡线参数 (`line_tracking_config.h`)
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `LINE_TRACKING_DEFAULT_BASE_RPM` | 50 | 默认循迹基础速度 |
| `LINE_TRACKING_PID_KP_MILLI` | 1 | Kp=0.001, 决定纠偏力度 |
| `LINE_TRACKING_PID_KD_MILLI` | 10 | Kd=0.010, 抑制位置突变 |
| `LINE_TRACKING_TURN_LIMIT_PERCENT` | 150 | 差速上限=base的150% |
| `LINE_TRACKING_DEADBAND` | 0 | 中心死区, 0=关闭 |

### 灰度标定 (`gray_sensor_config.h`)
安装高度或光照变化后需重新标定 `GRAY_SENSOR_WHITE_VALUES` 和
`GRAY_SENSOR_BLACK_VALUES` 数组。

### yaw 角环参数 (`yaw_control.c`)
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `YAW_PID_DEFAULT_KP_MILLI` | 180 | Kp=0.180 |
| `YAW_PID_DEFAULT_KD_MILLI` | 1200 | Kd=1.200 |
| `YAW_TARGET_RAMP_STEP_DEG10` | 5 | 目标斜坡步长 (720°/s) |
| `YAW_DEADBAND_DEG10` | 12 | 死区 1.2° |
| `YAW_REACQUIRE_DEG10` | 25 | 重捕获阈值 2.5° |

### 直角弯参数 (`app_tasks.c`)
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `CORNER_ADVANCE_COUNTS` | 2500 | 检测到直角后直行编码器计数 |
| `CORNER_TURN_TARGET_DEG10` | 900 | 转向角度 90° |
| `CORNER_YAW_SETTLE_DEG10` | 12 | 到位判定 1.2° |
