## 按键交互

- PA18：仅在主菜单循环选择任务1至任务6；内部下拉，高电平按下。
- PB21：主菜单中进入所选任务页面。
- 本阶段不提供退出任务页面功能，复位后返回主菜单。
- 任务2至任务5完成或故障且图传已关闭后，PB21可以重新执行当前任务。
- 各任务OLED以秒显示执行时间，完成或故障后冻结最终耗时；任务4从READY后车辆真正启动时开始计时。

## 各任务行为

### 任务1

进入页面后：

1. 第一次按 PB21 发送 `5A 01 A5`，开启图传。
2. 第二次按 PB21 结束任务。
3. 结束1秒后发送 `5A 02 A5`，关闭图传。

### 任务2

进入页面后再次按 PB21：

1. 装入任务2专属循线与速度环配置。
2. 开启图传并开始一圈循线。
3. 启动后500ms内不解锁终点；随后连续50ms确认已经驶离起点横线。
4. 解锁后首次检测到至少4路强黑即认为进入A点横线，并在同一10ms周期直接锁存TB6612制动。
5. 两轮停稳后完成，1秒后关闭图传。

任务2固定配置：

- 基础速度：200 RPM
- 循线 PD：Kp=6、Ki=0、Kd=25（存储值为实际值乘1000）
- 弯道限速：60%，最高100 RPM
- 速度环：Kp=350、Ki=280、Kd=0
- 编码器换算：2500 counts/rev
- 无任务4的3秒启动低速保护

### 任务3

进入页面后只使能步进电机并将管道调平，车轮保持急停，图传和计时尚未开始。再次按 PB21 后开启图传、开始计时并执行 `O -> +5cm -> -5cm`。

六任务默认参数现统一定义在 `Component/config/task_params.c`，字段说明见
`Component/config/task_params.h`。菜单Task1～Task6使用独立参数块；以下数字
是迁移时保留的实车基线，不再以 `control2.c` 中的散落变量作为调参入口。

稳定参数保持为提交 `fd8b54b` 的值，包括：

- 位置/速度级联增益：3000 / 1200
- 期望球速上限：80 px/s
- 正/负倾角上限：120 / 80脉冲
- +5cm / -5cm目标：225 / 105像素
- 步进电机速度/加速度：110 RPM / 130

完成1秒后关闭图传；底层继续保持钢球最终位置。

### 任务4

进入页面后立即开启图传并控制钢球到中心，车轮保持ESTOP：

1. 钢球误差不超过10像素并稳定500ms后显示 `READY`。
2. 只有在 `READY` 页面再次按 PB21才允许小车行驶。
3. 按键边沿前若钢球重新偏出容差，返回居中阶段，不发车、不报故障。
4. 完成或故障1秒后关闭图传。

任务4保持 `f0f31c8` 稳定参数：

- 目标距离：18000 counts
- 基础速度：180 RPM
- start_ff / end_ff：+20 / -35脉冲
- 运行超时：8000ms
- 循线 PD：Kp=10、Ki=0、Kd=15
- 速度环：Kp=80、Ki=50、Kd=0
- 编码器换算：1500 counts/rev
- 3秒启动低速保护和原定距减速/制动逻辑保持不变

### 任务5

进入页面后再次按 PB21，开启图传并执行完整一圈循线与动态管球：

1. `PREPARE`：车轮保持ESTOP，先将钢球稳定在中心500ms。
2. `TRACKING`：自动发车；连续确认已离开A点横线后解锁终点。
3. 再次稳定检测到A点横线后进入斜坡制动，编码器只用于卡死保护、行程统计和末段减速。
4. 两轮停稳后继续保持钢球，中心稳定500ms后完成。
5. 完成或故障时冻结OLED耗时，1秒后关闭图传；关闭后PB21可重跑。

任务5保持提交 `8c092db` 的通过参数：

- 基础速度：150 RPM
- 独立循线 profile：`LINE_TRACKING_PROFILE_TASK5_LAP_BALL`（初始 Kp/Kd=10/15）
- 独立速度 profile：`SPEED_PROFILE_TASK5_LAP_BALL`（初始 Kp/Ki=80/50，1500 CPR）
- 球中心目标：165像素
- 行驶态管球 Kp_pos / Kp_vel：1500 / 1200
- 球速滤波系数：250/1000
- 圈长估计：68008 counts；减速区：20000 counts；末段最低速度：90 RPM
- 启动/制动前馈：+20 / -35脉冲；弯道前馈：900
- 总超时：30000ms

### 任务6

1. 进入页面后只使能步进电机并将管道调平，车轮保持急停。
2. 用户可将球放到管道任意位置；OLED显示最新视觉X坐标。
3. 再按 PB21 时读取不超过300ms的最新球帧，将当前位置快照为本圈目标。
4. 目标采样成功后开启图传、开始计时，按Task6独立参数运行完整一圈。
5. A点停车后继续保持本次动态目标；完成/故障时冻结耗时，1秒后关闭图传，PB21可重跑。
6. 若没有有效新鲜球帧，保持WAIT，不启动图传、计时或车轮。

Task6参数在 `Component/config/task_params.c` 的 `g_task6_params` 中独立调节，
一圈、管球、循线和速度参数位于 `g_task6_params.lap`；不再使用旧 `g_t6_*`
散落变量。循线和速度环分别选择 Task6 profile，但实际指向 Task6 自己的
`.lap.line` 和 `.lap.speed`。任意位置启动/停车前馈默认按 X=150～195 区间
插值，端点由 `ff_low_x/ff_high_x`、`start_ff_low/high`、
`brake_ff_low/high` 独立配置。

## 图传协议

MCU与MaixCam使用 UART3（PB2/PB3，115200）：

- `5A 01 A5`：幂等开启图传
- `5A 02 A5`：幂等关闭图传

图传关闭只停止网络图像流，不停止MaixCam通过UART发送钢球坐标帧。
