## 三、Task2 钢珠平衡 — 当前调参状态

**控制方案：速度级联 (方案一)**
```
外环：desired_vel = Kp_pos × 位置误差
内环：motor_pulses = Kp_vel × (desired_vel - ball_vel)
```

**当前参数 (Keil Watch 直接改, volatile 全局变量)：**

| 变量 | 值 | 作用 |
|------|-----|------|
| `g_t2_kp_pos` | 3500 | 外环增益，越大接近越快 |
| `g_t2_kp_vel` | 200 | 内环增益，越大刹车越猛 |
| `g_t2_max_desired_vel` | 300 | 期望速度上限 |
| `g_t2_max_tilt` | 200 | 最大倾角(脉冲) |
| `g_t2_dead_zone` | 50 | 死区(脉冲)，<此值球不动 |
| `g_t2_dead_boost` | 65 | 死区补偿(脉冲)，突破摩擦 |
| `g_t2_dead_vel_th` | 10 | 球速<此值触发补偿 |
| `g_t2_target_x` | 250 | 目标位置(像素) |
| `g_t2_tilt_sign` | 1 | 倾角方向(+1/-1) |
| `g_t2_tolerance_px` | 10 | 到位容差 |
| `g_t2_stable_time_ms` | 500 | 稳定时间 |

**机械情况：** 管子内壁粗糙，摩擦大。dead_zone 和 dead_boost 已经加大过。

**调试方法：**
- 球冲过头 → 加大 `g_t2_kp_vel` (200→250→300)
- 球到不了目标 → 加大 `g_t2_kp_pos` (3500→4000)
- 球在目标附近微抖 → 减小 `g_t2_dead_boost` (65→50) 或加大 `g_t2_dead_zone`
- 球差一点到位不动 → 加大 `g_t2_dead_boost` (65→80→100)
- 从零调试：先关 dead_zone/dead_boost(=0)，调 kp_pos 到球能到目标附近，再调 kp_vel 到不超调，最后恢复 dead_zone/dead_boost

## 四、Task1 巡线一圈

**文件：** `control2.c` task1, `line_tracking_config.h` (巡线PD参数)

**当前巡线算法：** 新版 (从 history/line_tracking 移植)，含丢线搜索+弯道减速+轮速整形+**全黑检查点检测**。

**Task1 专用参数 (`control2.c`)：**

| 参数 | 值 | 作用 |
|------|-----|------|
| `TASK1_BASE_RPM` | 180 | 巡线速度 |

**巡线PD参数 (`line_tracking_config.h`)：**

| 参数 | 值 | 作用 |
|------|-----|------|
| `KP_HIGH_MILLI` | 10 | PD Kp (×1000)，整数死区≈50px |
| `KD_MILLI` | 15 | PD Kd (×1000) |
| `DEADBAND` | 0 | 中心死区(已关闭) |
| `TURN_LIMIT_NUM/DENOM` | 3/2 | 差速上限=base×1.5 |
| `TURN_SLEW_DOWN_RPM` | 5 | 出弯回正限速 5RPM/10ms |
| `DIRECTION_RELEASE_TICKS` | 5 | 方向锁存解除确认 50ms |
| `CORNER_SPEED_PERCENT` | 60 | 弯道速度比例 |
| `CORNER_SPEED_MAX_RPM` | 100 | 弯道绝对上限 |
| `WHEEL_ACCEL_RPM_PER_TICK` | 8 | 轮速变化率限制 |
| `CHECKPOINT_CHANNEL_MIN` | 6 | 全黑检查点：强黑≥此值判定全黑区 |
| `CHECKPOINT_STOP_COUNT` | 3 | 全黑检查点达到此次数后自动停车 |

**全黑检查点机制 (新增)：**
当 8 路灰度中强黑通道数 ≥ 6 时，判定为全黑区（如停止线/宽黑标），
车辆直行通过（turn=0，保持base），并累计遇到次数。
达到 `CHECKPOINT_STOP_COUNT`(3) 次后自动停车。
此机制替代固定编码器距离判停，在 service 层视为正常到达(非故障)。

**状态机：** IDLE → TRACKING → BRAKING → COMPLETE
启动后跳过初始启停线 (grace period 500ms), 然后监测终点启停线。
已去掉原来的 WAIT_LEAVE 状态, 改用时间 grace period 跳过出发线。

## 五、Task3 O→+5cm→-5cm

**原理：** task3 调用 task2 作为控制底层，只负责根据时机切换目标点。

**状态机：** IDLE → GO_POS5 → HOLD_POS5 → GO_NEG5 → COMPLETE
```
         到达+5cm    停留N秒     到达-5cm    完成
```

**到达判定：** Task3 用自身像素阈值独立判断，不依赖 task2 的 reached 标志。
`|球位置 - 目标| < g_t3_arrive_threshold_px` 且持续 `g_t3_arrive_stable_ms` → 判定到达。

**可调参数 (在 Watch 改)：**

| 变量 | 默认 | 含义 |
|------|------|------|
| `g_t3_target_pos5` | 225 | +5cm 相机 X 坐标 |
| `g_t3_target_neg5` | 105 | -5cm 相机 X 坐标 |
| `g_t3_arrive_threshold_px` | 15 | 到达判定像素阈值 (越小越严) |
| `g_t3_arrive_stable_ms` | 300 | 阈值内持续此时长才算到达 (ms) |
| `g_t3_hold_pos5_ms` | 2000 | 到达 +5cm 后停留时间 (ms) |

**标定方法：** 球放 +5cm 刻度 → 看 OLED 上 X 值 → 填入 `g_t3_target_pos5`。同法标 `g_t3_target_neg5`。

**OLED 显示 (Task3 运行时)：**
```
+5/HOLD/-5/DONE  T:xxxms   ← 状态名 + 总耗时(仅COMPLETE显示)
Tg:225 X:230               ← 目标位置 + 当前球位置
Er:+5  Mot:+120            ← 误差 + 电机目标
Hld:1234ms  /  St:280 R:N  ← 停留计时(HOLD状态) / 稳定计时+reached(运动状态)
```

## 六、Task5 巡线 + 管球并行

**文件：** `control2.c` task5

**原理：** 小车巡线行驶的同时, 步进电机控制管道使钢珠保持在目标位置。
巡线完成 (检测到启停线) 后自动停车并停止管球控制。

**状态机：** IDLE → TRACKING → COMPLETE
启动后跳过初始启停线 (grace period 500ms), 然后监测终点启停线。

**可调参数：**

| 参数/变量 | 默认 | 含义 |
|------|------|------|
| `TASK5_BASE_RPM` | 180 | 巡线速度 (宏, 需重编译) |
| `g_t5_ball_target_x` | 250 | 钢珠目标 X 坐标 (Watch 直接改) |

**集成方式：** task5_step 每周期同时调用 line_tracking_service_step_10ms (车轮) 和 task2_step (步进电机), 两路控制完全独立并行。

**OLED 显示 (Task5 运行时)：**
```
TRACK/DONE   T:xxxms        ← 状态名 + 总耗时
B:230  Tg:250              ← 球位置 + 球目标
Er:+5   S:3                ← 球误差 + 强黑通道数
M:+120  OK/..              ← 电机目标 + 球到位标志
```
